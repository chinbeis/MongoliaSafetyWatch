# Олон Нийтийн Аюулгүй Байдал (CatchPred)

A Mongolian-language public-safety information site. It shows **aggregated, anonymised** official
crime statistics (from the National Statistics Office, 1212.mn) on maps and charts, prevention
education, the official emergency channels, and an anonymous, area-level community map.

It is **not** an official police portal and does not accept crime reports. Privacy is the core
constraint: no personal data, no exact locations, no individual cases.

## Stack

Next.js 16 (App Router, React 19, React Compiler) · TypeScript · Tailwind CSS v4 ·
MapLibre GL · Recharts · Drizzle ORM on Neon Postgres · Vitest.

## Getting started

Requires Node 24 (see `.nvmrc`) and pnpm (version pinned in `package.json`).

```bash
corepack enable          # once, provides the pinned pnpm
pnpm install
cp .env.example .env     # then fill in values — never commit .env
pnpm dev                 # http://localhost:3000
```

Without a `.env` the site still runs: the statistics pages are static, and the community map shows
an error state because there is no database. Point `DATABASE_URL` at a **Neon development branch**,
never at production, when working locally.

## Environment

See `.env.example` for the full list. `src/lib/env.ts` validates the server variables on first use
and **refuses to run in production** when a required secret is missing, shorter than 32 characters,
or still a placeholder.

| Variable | Required in prod | Purpose |
|---|---|---|
| `DATABASE_URL` | yes | Neon Postgres (community map only) |
| `COMMUNITY_CAPTCHA_SECRET` | yes | HMAC key for the fallback human check |
| `RATE_LIMIT_SALT_SECRET` | yes | HMAC key for daily-rotating, non-reversible client keys |
| `ADMIN_TOKEN` | yes | Bearer token for `/admin` moderation |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` / `TURNSTILE_SECRET_KEY` | no | Cloudflare Turnstile bot protection |
| `NEXT_PUBLIC_SITE_URL` | yes | Canonical URL for metadata, sitemap, OG images |
| `NEXT_PUBLIC_MAP_STYLE_URL` | no | MapLibre style URL (defaults to OpenFreeMap dark) |
| `SENTRY_DSN` | no | Error reporting; disabled when empty |
| `COMMUNITY_REPORTS_READONLY` | no | `1` = emergency switch, community map becomes read-only |

## Commands

```bash
pnpm dev           # development server
pnpm build         # production build (works with no env at all)
pnpm start         # serve the production build
pnpm lint          # eslint
pnpm typecheck     # tsc --noEmit
pnpm test          # vitest (unit + route-handler tests)
pnpm import:1212   # refresh official statistics from 1212.mn
pnpm db:migrate    # apply drizzle/*.sql — see docs/DEPLOY.md before touching production
```

## Data

There are two independent data paths:

1. **Official statistics** — a static snapshot in `src/data/` generated by
   `scripts/import-1212-crime.mjs` from the 1212.mn PXWeb API and bundled at build time. It never
   touches the database. A scheduled GitHub Action re-runs the importer and opens a pull request
   when new data is published; a human reviews and merges it.
2. **Community map** — anonymous, area-level pins stored in Postgres (`community_reports`),
   written through `/api/community-reports` with bot protection and rate limiting.

## Deployment

Hosted on Vercel (functions in `sin1`, next to the Neon database in `ap-southeast-1`). CI runs lint,
typecheck, tests and a build on every pull request. See `docs/DEPLOY.md` and `docs/RUNBOOK.md`.
